# UK Property Market & Service Charge Analysis

**Goal:** To analyze regional trends in property costs and service charge fluctuations using SQL and Power BI.

### Tech Stack

- **Language:** SQL (PostgreSQL/MySQL)
- **Visualization:** Power BI
- **Concepts:** CTEs, Window Functions, DAX Measures

### The Business Problem

As a Service Charge Analyst, I identified the need for more dynamic reporting beyond static spreadsheets to track compliance and cost outliers across UK regions. This would allow for better assestment of the costs within the company being passed to our clients which is the driving motivator of my work.

### The Data Source

I have collected the full UK Housing Price Index CSV from the Gov.UK website, I have chosen to take the full file as this give me maximum control over what information is truly relevant rather than opting for any of the preprocessed options they offer.

### Key Insights

- Identified a [X]% increase in service charges in the Midlands area.
- Flagged [X] properties with inconsistent billing logic using SQL CASE statements.
